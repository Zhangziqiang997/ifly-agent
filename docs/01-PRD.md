## 1. 产品定义

### 1.1 一句话定义

> **参数智能体**：面向智慧教育招投标场景的 AI 驱动参数分析系统。  
> 输入一份智慧黑板招标文件 → 识别控标方 → 逐条对比讯飞产品参数 → 标出正/负偏离 → 对不满足项生成应对建议。

### 1.2 目标用户

| 用户角色 | 核心场景 | 痛点 |
|----------|---------|------|
| 讯飞售前/投标经理 | 拿到招标文件后、投标准备阶段 | 人工对比 50+ 条参数耗时 2-3 天，容易遗漏 |
| 讯飞销售/渠道经理 | 招标意向公示期（通常 5 个工作日） | 看不出参数倾向性，缺乏质疑依据 |

### 1.3 使用流程

```
用户上传招标文件（PDF/Word/Excel）
        │
        ▼
系统自动解析 → 提取结构化参数列表
        │
        ▼
三层分析引擎运行（3-10 秒）
        │
        ▼
输出应标分析报告：
  ① 控标方判定 + 置信度
  ② 逐条参数正/负偏离标记
  ③ 负偏离项应对建议
```

## 2. 功能规格

### 2.1 模块一：参数知识库

**能力定义**：系统维护一份结构化的产品参数数据库，涵盖竞品和讯飞自身产品的技术规格。

**数据范围**：
- 竞品厂商：希沃（SEEWO）、鸿合（HiteVision）、海康威视（HIKVISION）
- 讯飞产品：讯飞智慧黑板系列
- 参数分类：显示、触控、摄像、音频、护眼、无线投屏、接口、物理结构、OPS 电脑、教学软件、智能笔、视频展台、集控管理、AI 能力等

**数据操作**：
- 支持按厂商、产品型号、参数类别查询
- 支持新增厂商/产品/参数条目
- 每条参数记录来源文档，可溯源

---

### 2.2 模块二：招标文件解析

**能力定义**：自动识别上传文件的格式，提取其中的参数表格/参数列表，归一化为统一结构。

**支持的输入格式**：
- PDF（含扫描件 OCR）
- Word（.docx / .doc）
- Excel（.xlsx / .xls）

**处理步骤**：
1. 自动识别文件格式
2. 提取参数文本（表格行 / 编号列表 / 段落）
3. 识别参数标记（★ 星号废标项 / △ 三角扣分项 / ◆ 证明材料要求）
4. 归一化为统一 JSON 结构（见 §3.2）

**输出**：结构化招标参数列表。

---

### 2.3 模块三：控标方识别（横向对比）

**能力定义**：判定招标文件中哪些参数是"独有特征"——市面上仅某一家厂商能满足的规格，从而推断控标方。

**算法**（纯程序执行）：

```
对于每条招标参数：
  满足的厂商 = []
  对于每家竞品（希沃/鸿合/海康）：
    如果 竞品对应参数 ≥ 招标要求：
      满足的厂商.append(竞品名)

  如果 len(满足的厂商) == 1：
    标记为"独有特征"，归属 = 满足的厂商[0]

  如果 len(满足的厂商) == 0：
    标记为"异常：数据库中没有厂商满足此要求"
```

**输出**：
- 控标方判定 + 置信度（独有特征命中数 / 总有效参数数）
- 每家命中的独有特征清单（含参数名称和来源）
- "无人满足"异常项列表

**置信度解读**：

| 命中率 | 结论 |
|--------|------|
| > 60% | 高度可疑，强烈指向某一家 |
| 30-60% | 部分倾向，可能混合控标 |
| < 30% | 无明显控标倾向 |

---

### 2.4 模块四：参数匹配（纵向对比）

**能力定义**：将招标要求逐条与讯飞产品参数对比，判定正偏离或负偏离。采用"程序粗筛 → AI 精判"双层架构。

#### 第一层：程序粗筛

| 匹配类型 | 方法 | 示例 |
|----------|------|------|
| 数值直接比较 | 正则提取数字 + 单位，比大小 | 要求 ≥ 500cd/m²，讯飞 520 → 满足 |
| 单位归一化 | 映射表统一单位后比较 | 4K = 3840×2160 |
| 关键词精确匹配 | 字符串包含 / Jaccard 相似度 | "护眼认证" → 匹配成功 |
| 范围判断 | 提取区间值比较 | 要求 ≤ 28mm，讯飞 25mm → 满足 |

> 对于复合参数（一条含多个子指标），先拆分为原子指标再逐个匹配。

#### 第二层：AI 语义精判

**触发条件**（满足任一）：
- 程序粗筛后仍无法判定（无公共关键词、无数值可比）
- 纯功能/软件类描述参数
- 需要生成应对建议的负偏离项

**输出分类**：

| 类型 | 标记 | 含义 | 下一步动作 |
|------|------|------|-----------|
| 正偏离 | 🟢 | 讯飞规格 ≥ 招标要求 | 标出优势 |
| 负偏离（说辞可改） | 🟡 | 能力有但描述不同 | 改写为招标对应说法 |
| 负偏离（真不满足） | 🔴 | 确实达不到 | 生成质疑话术 |

---

### 2.5 模块五：应对建议生成

**能力定义**：针对负偏离项，按优先级自动生成应对策略。

| 优先级 | 策略 | 适用场景 |
|--------|------|---------|
| P0 | **改说辞** | 讯飞有能力，但参数文档描述方式不同 |
| P1 | **质疑话术** | 讯飞确实不满足，从三个角度生成质疑论点 |
| P2 | **渠道协调** | 无法通过改说辞或质疑解决 |

**质疑话术三维度**：
1. **教学场景实用性**：质疑该参数在日常教学中的必要性
2. **生态与功能完整性**：单一参数不代表整体方案优劣
3. **法规与标准依据**：现行国标/行标是否有此要求

## 3. 数据格式规范

### 3.1 竞品 / 讯飞参数 JSON

```json
{
  "vendor": "厂商名",
  "product": "产品型号",
  "category": "产品品类",
  "updated": "数据更新日期",
  "params": [
    {
      "id": "唯一标识",
      "category": "参数分类",
      "name": "参数名称",
      "spec": "原始描述文本",
      "indicators": [
        {"name": "子指标名", "value": "数值", "unit": "单位", "comparator": "eq/gte/lte/gt/lt"},
        {"name": "子指标名", "value": "特征值", "unit": "feature/certification", "comparator": "eq"}
      ],
      "star_mark": false,
      "cert_required": false
    }
  ]
}
```

### 3.2 招标参数 JSON（解析器输出）

```json
{
  "project": "项目名称",
  "date": "招标日期",
  "items": [
    {
      "seq": 1,
      "category": "参数分类",
      "name": "参数名称",
      "requirement": "原始招标要求文本",
      "star_mark": false,
      "triangle_mark": true
    }
  ]
}
```

### 3.3 分析结果 JSON

```json
{
  "controller": {
    "vendor": "控标方",
    "confidence": 0.67,
    "hit_details": [{"param_seq": 3, "param_name": "...", "hit_vendor": "..."}]
  },
  "anomalies": [{"param_seq": 9, "param_name": "...", "reason": "所有厂商均不满足"}],
  "matching": [
    {
      "seq": 1,
      "bid_req": "招标要求文本",
      "xunfei_spec": "讯飞对应参数文本",
      "deviation": "positive | negative_wording | negative_real",
      "match_method": "program | ai_semantic",
      "suggestion": "应对建议文本（负偏离时非空）"
    }
  ]
}
```

## 4. 非功能性需求

| 需求 | 标准 |
|------|------|
| 响应速度 | 单次分析（含 AI 调用）≤ 10 秒 |
| 数据安全 | 招标文件处理后在本地完成，不上传至第三方 |
| 可用性 | Web 页面（Streamlit），浏览器打开即用 |
| 可扩展性 | 新增竞品厂商/产品型号只需添加 JSON 文件，不修改代码 |

---

## 5. Out of Scope（不做）

- ❌ 招标评分自动计算
- ❌ 全行业（几十家）厂商数据库
- ❌ 用户登录/权限系统
- ❌ 历史记录持久化 / 报告导出
- ❌ 移动端适配
- ❌ 参数自动抓取/更新（爬虫）

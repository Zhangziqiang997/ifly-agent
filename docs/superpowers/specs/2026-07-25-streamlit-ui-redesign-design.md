# 参数智能体 Streamlit UI 重写设计

日期：2026-07-25

## 1. 目标与范围

重写 `src/app.py`，将参数智能体 Demo 的 Streamlit 界面严格对齐工作区根目录的 `prototype_design.html`。界面用于比赛演示，只运行内置样例，不处理用户真实文件。

本次实现遵守以下边界：

- 分析入口固定调用 `run_analysis("sample-bid.json")`。
- 不读取或保存用户上传内容。
- 不创建数据库，不修改现有 JSON 数据。
- 参数知识库仅只读展示现有讯飞与三家竞品 JSON。
- 不修改 `src/engine.py` 及其返回值契约。
- 只重写 `src/app.py`，并按需要补充 UI 测试。

## 2. 实现策略

采用“HTML/CSS 高保真骨架 + Streamlit 原生交互”的混合方案：

- 固定侧栏、统计卡、控标卡、分类偏离图、对比表和建议面板使用 HTML/CSS 渲染，以精确复刻原型。
- 页面导航、按钮、筛选、状态管理和引擎调用使用 Streamlit 原生能力。
- 引擎文本在插入 HTML 前统一转义，防止数据内容破坏页面结构。

不采用全 HTML 组件嵌入方案，因为其与 Python 状态通信复杂；不采用纯 Streamlit 原生布局，因为难以严格复刻原型的固定侧栏与表格结构。

## 4. 页面与组件

### 4.1 固定侧栏

侧栏包含：

1. 上传招标文件
2. 分析结果
3. 参数知识库

分析完成后，“分析结果”显示“新”标记。底部显示“系统就绪 · v3.0”。侧栏用于切换 `st.session_state.page`，页面切换不重复运行引擎。

### 4.2 上传招标文件

首次打开进入上传页。页面保留原型的拖拽上传区外观，但明确标注“演示模式”，避免暗示系统会处理真实文件。

主操作为“加载样例并开始分析”。点击后：

1. 展示七步分析进度；
2. 调用 `run_analysis("sample-bid.json")`；
3. 校验核心结果结构；
4. 将结果保存至 `st.session_state.result`；
5. 切换到分析结果页。

页面不提供真实文件选择器，不创建 `_uploaded.json`。

### 4.3 分析结果

分析页在同一页面内展示：

- 项目名称、参数总数和分析完成时间；
- 四张统计卡：总参数、正偏离、说辞可改、真负偏离；
- 控标方、置信度环形图、嫌疑等级和独有特征命中列表；
- 按参数类别聚合的偏离分布图；
- 逐条参数对比表；
- 负偏离应对建议。

偏离分布图由 `matching[].category` 和 `matching[].deviation` 动态聚合，不使用原型中的硬编码数字。

对比表支持四种筛选：

- 全部；
- 正偏离；
- 说辞可改；
- 真负偏离。

筛选只改变表格内容，不修改原始分析结果。负偏离条目在建议区域显示招标要求、讯飞规格、分析详情和建议；正偏离不生成建议卡。

### 4.4 参数知识库

知识库页读取：

- `data/xunfei/xunfei.json`
- `data/competitors/xiwo.json`
- `data/competitors/honghe.json`
- `data/competitors/haikang.json`

页面以原型卡片样式只读展示厂商、产品、参数分类、参数名称和规格。支持厂商、品类和关键词筛选，不提供新增、编辑、删除或持久化操作。

## 5. 状态与数据流

`st.session_state` 至少维护：

- `page`：当前页面；
- `result`：最近一次样例分析结果；
- `analysis_complete`：是否已有可展示结果；
- `analysis_time`：完成时间；
- `comparison_filter`：对比表筛选条件。

主流程：

```text
首次打开
  → 上传页
  → 点击加载样例
  → run_analysis("sample-bid.json")
  → 校验结果
  → 保存 session state
  → 分析结果页
  → 筛选表格 / 查看建议 / 切换知识库
```

“重新分析”清除旧结果并再次运行同一个样例。

## 6. 异常处理

- 引擎执行异常：保留在上传页，显示简洁中文错误。
- 核心字段缺失：将结果判定为格式错误，不渲染残缺报告。
- 可选字段缺失：使用空字符串或“暂无数据”等占位内容。
- 知识库文件读取失败：仅在知识库页显示对应文件错误，不影响已有分析结果。
- 所有动态文本在 HTML 插值前调用 `html.escape()`。

## 7. 验收标准

### 7.1 功能

- 首次打开显示上传页，不自动分析。
- 主按钮只调用 `run_analysis("sample-bid.json")`。
- 分析结果切换页面后仍然保留，不重复调用引擎。
- 四类筛选结果数量与 `summary` 一致。
- 建议区域只展示 `negative_wording` 和 `negative_real`。
- 知识库正确读取四份现有 JSON，且无写操作。

### 7.2 视觉

- 220px 固定侧栏、深海军蓝背景、卡片层级和状态色与原型一致。
- 分析页采用四张统计卡、340px 控标卡和右侧偏离分布图。
- 表格工具栏、标签、建议卡、悬停和滚动条样式对齐原型。
- Streamlit 默认顶部栏、白色背景和多余内边距被正确处理。

### 7.3 验证

- Python 语法检查通过。
- `run_analysis("sample-bid.json")` 返回结果可被 UI 完整消费。
- Streamlit 使用指定命令成功启动，无启动时异常。
- 浏览器逐页检查上传、分析、知识库、导航、筛选和建议展开。
- 检查浏览器控制台，不存在影响交互的前端错误。

## 8. 非目标

- PDF、Word、Excel 或 JSON 的真实上传解析；
- 用户数据保存；
- 参数知识库编辑；
- 登录、权限和移动端适配；
- 报告导出和历史记录；
- 修改核心分析算法。

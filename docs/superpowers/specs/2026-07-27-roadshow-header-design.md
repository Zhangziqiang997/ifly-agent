# 路演 PPT 模板页眉设计

## 目标

在 `presentations/路演PPT.html` 中复用公司模板的顶部蓝色页眉：除首页、现场演示过渡页和结尾页外，每个内容页顶部显示一条横跨页面的蓝色渐变矩形，并在右上角预留 logo 空间。当前不植入 logo，待用户提供素材后再补入。

## 方案

- 给内容页面增加统一的 `template-header` 结构，使用品牌天蓝到主蓝的渐变，保持与现有品牌色一致；现场演示页保持无页眉，作为切出原型展示的过渡页。
- 页眉高度固定为 104px，并将中间页面内容区的上内边距增加到 150px，避免覆盖标题和正文。
- 将已有 `page-tag` 下移到页眉下方；首页、现场演示页和结尾页保持现有布局，不增加页眉。
- 页眉右侧保留无可见边框的 logo 占位区，避免现在出现临时文字或错误标识。
- 不改动页面文案、页面顺序、演示脚本、架构图和其他并行工作文件。

## 验证

- 静态检查内容页数量、首页/现场演示页/结尾页排除规则及页眉 DOM。
- 使用本地浏览器渲染检查首页、内容页、深色 Demo 页和结尾页，确认页眉不遮挡内容。
- 运行 `git diff --check`，并检查目标文件无冲突标记。

# AI 投标决策中心静态演示页设计

## 目标

从参考截图独立复刻一个桌面端页面，用于前端演示与后续功能接入；不修改或复用仓库中既有原型。

## 交付结构

```text
ai-bidding-decision/
  index.html
  styles.css
  app.js
```

页面无需构建步骤或第三方依赖，可由浏览器直接打开。HTML 负责语义化区域，CSS 负责桌面端视觉复刻，JavaScript 仅放置模拟数据与预留交互入口。

## 页面范围

- 固定桌面宽屏布局：左侧导航、顶部工具栏和主内容区。
- 主内容区：标题说明、知识库接入、AI 风险识别、AI 分析报告、核心工作入口、AI 研判结果和讯飞 AI 产品能力。
- 使用 CSS 绘制卡片、标签、按钮、分隔线及简单图标效果；不引入外部图片或图标库。
- 按钮和导航项展示静态可交互状态，不请求后端。

## 可扩展边界

- 所有可变展示数值和列表项集中在 `app.js`，未来可被接口结果替换。
- 每个主要模块具有稳定 class 和 `data-section` 标记，便于迁移至任意前端框架或拆分组件。
- 无接口失败处理：此交付是纯静态视觉演示，未来接入时由前端应用层处理加载、错误和空状态。

## 验证

在 Chromium 中以 1680×940 截图检查：布局比例、间距、边框、字体层级、配色和页面无横向溢出。

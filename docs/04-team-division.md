### 💻 原型开发 ×2

**核心任务**：

**开发 A（后端引擎）**：
- [ ] **7.25**：实现 `src/parser.py` — 参数解析 + 数值提取 + 单位归一化
- [ ] **7.25**：实现 `src/matcher.py` — 第一关 `quick_match()` + 第二关 `identify_controller()`
- [ ] **7.26**：实现 `src/advisor.py` — 第三关 AI 语义精判（Prompt 封装 + Kooky API 调用）
- [ ] **7.26**：实现 `src/engine.py` — 三层串联的主引擎
- [ ] **7.27**：Bug 修复 + 备用录屏

**开发 B（前端 + 集成）**：
- [ ] **7.25**：搭建 Python 环境 + Streamlit 项目骨架
- [ ] **7.26**：实现 `src/app.py` — 三页面 Streamlit UI
- [ ] **7.26**：端到端联调（上传 JSON → 分析 → 结果展示）
- [ ] **7.27**：UI 打磨 + 备用录屏

**技术规范**（开发二人必须对齐）：
- 代码风格：函数式为主，每个函数 ≤ 50 行
- 文件命名：`src/parser.py`, `src/matcher.py`, `src/advisor.py`, `src/engine.py`, `src/app.py`
- 数据路径：统一从 `data/` 读取，使用相对路径
- AI 调用：封装为独立函数 `call_ai(prompt: str) -> dict`，方便切换模型/降级

**AI 工具建议**：
- 代码生成：描述函数签名 + 输入输出 → AI 写实现
- 调试：贴报错信息 → AI 诊断
- 不要做的事：让 AI 一次写 500 行代码（容易出 bug，难调试）

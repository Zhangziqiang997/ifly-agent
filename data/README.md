# 数据层说明

## 目录结构

```
data/
├── competitors/        # 竞品参数库
│   ├── xiwo.json       # 希沃智慧黑板参数（15条）
│   ├── honghe.json     # 鸿合智慧黑板参数（15条）
│   └── wenxiang.json   # 文香智慧黑板参数（15条）
├── xunfei/
│   └── xunfei.json     # 讯飞智慧黑板参数（15条）
├── samples/            # 样例招标文件（用于Demo）
│   └── README.md
└── README.md           # ← 本文件
```

## 数据格式

所有参数文件使用统一的 JSON Schema：

```json
{
  "vendor": "厂商名",
  "product": "产品型号",
  "category": "产品品类",
  "updated": "数据更新日期",
  "params": [
    {
      "id": "唯一标识",
      "category": "参数分类",
      "name": "参数名称",
      "spec": "参数规格（原始描述文本）",
      "value": "归一化数值（可为数字/字符串枚举）",
      "value_type": "参数类型标注（可选）",
      "unit": "单位（数字型用具体单位，特征型用feature/certification/spec等）",
      "comparator": "比较方式：eq/gt/gte/lt/lte"
    }
  ]
}
```

## Demo演示建议

1. **用"希沃控标"样例**：样例招标文件中混入4条希沃独有特征 → 系统正确识别出希沃
2. **用"鸿合控标"样例**：换一份 → 系统正确识别出鸿合（展示通用性）
3. **强调"不做评价"**：识别出控标方后，声明"这是数据层面的特征匹配，不做价值判断"

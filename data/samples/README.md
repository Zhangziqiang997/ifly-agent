# 样例招标文件

这里是用于 demo 演示的招标文件样例。

## 样例设计原则

- **数据量**：12 条参数（5条通用 + 4条希沃独有 + 2条鸿合独有 + 1条文香独有）
- **控标倾向**：本样例设计为"希沃控标"（命中率 4/12 ≈ 33%）
- **讯飞表现**：有正偏离项、有说辞可改项、有真不满足项——三类的例子都要有
- **格式**：CSV/Excel，方便直接读取演示

## 样例文件列表

| 文件 | 说明 |
|------|------|
| `sample_bid.csv` | 一份模拟"希沃倾向"的招标参数表 |
| `sample_bid_honghe.csv` | 一份模拟"鸿合倾向"的招标参数表（测试用） |
| `sample_bid_neutral.csv` | 一份无明显倾向的招标参数表（测试用） |

## 关于"控标嫌疑"的说明

演示时请务必强调：
> "我们不做任何道德或法律上的评判和评价。我们只做数据层面的控标特征识别。"

## 路演关键提醒

- ✅ **现场 Demo > 录屏视频 >>> PPT 截图**
- ✅ 每个环节用"AI 做了什么 + 人做了什么"的格式讲
- ✅ 主动提 1-2 个不足（显得诚实有思考）
- ❌ 不要照着 PPT 念
- ❌ 不要讲太多技术细节（评委里有非技术专家）
- ❌ 不要贬低竞品（你是在讯飞内部路演，别的产品线也是同事）

## Demo 演示流程（建议）

```
1. 打开 Streamlit 页面（提前加载好）
2. 上传样例招标文件（点击即分析）
3. 展示控标方识别结果："看，系统判定这份标是希沃控的，置信度67%"
4. 滚动参数对比表，指一条红色/黄色："这一条我们不满足，点击看建议"
5. 展开建议卡片，读一下AI生成的话术
6. 关闭 Demo，回到 PPT："整个过程不到30秒，而且只有最后一关调了AI"
```
